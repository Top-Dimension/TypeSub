# Security Policy

## Supported Versions

Security fixes focus on the current TypeSub pre-release.

| Version | Supported |
| --- | --- |
| 0.1.2 (pre-release) | :white_check_mark: |

## Reporting a Vulnerability

Open the [TypeSub Security page](https://github.com/Top-Dimension/TypeSub/security/advisories) and select **Report a vulnerability** to send a private report. If that button is unavailable, open a GitHub issue asking the maintainers for a private contact method. Keep the public issue limited to that request.

In your private report, please include the TypeSub version, operating system, affected feature, steps to reproduce, and what data or functionality may be affected. Share only the relevant parts of any logs or screenshots, with API keys, tokens, and personal information removed.

We aim to acknowledge reports within 7 calendar days and send a status update at least every 14 calendar days while a report is under active review. We may ask for more information if we cannot confirm the issue.

If we confirm a vulnerability, we will work on a fix or mitigation and coordinate disclosure with you. If we close a report, we will explain why. Please keep details private while we investigate and coordinate a disclosure date.
